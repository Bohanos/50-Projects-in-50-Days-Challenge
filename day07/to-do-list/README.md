# React To-Do List App 📝

A clean, interactive, and modular To-Do List application built with React. This project is **Day 07** of my 50-day coding challenge, focusing on component-based architecture, state management, and user event handling.

## 🚀 Features
* **Add Tasks:** Dynamically add new items to your daily task list.
* **Input Validation:** Prevents adding empty tasks to keep your list clean.
* **Clear All:** Instantly clear out the entire list with a single click.
* **Modular Structure:** Built using clean, separated React components for scalability.

## 🛠️ Built With
* **React** (Component architecture & Hooks)
* **JavaScript (ES6+)**
* **CSS3** (Styling)
* **Vite** (Build tool)
* **Oxlint** (Blazing-fast code linting)
