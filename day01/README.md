# Day 1: Personal Portfolio — 50-Day Coding Challenge

A simple, minimalist personal portfolio built as the first project for my 50-day coding challenge.

## 🚀 Features
- **Clean Navigation:** Minimalist header linking Home, About, and Projects pages.
- **Responsive Layout:** Styled with custom CSS using a dark theme palette.
- **Projects Showcase:** Highlights key projects including MEDCORE HMS, Berah's Barber Studio, and the Macedonian Call Cancer Foundation.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
