# Day 3: Custom Login Page — 50-Day Coding Challenge

A clean, centered, gold-themed login card interface built with HTML5 and CSS3.

## 🚀 Features
- **Structured Card Layout:** Utilizes a flexible container (`<form>`) with custom padding and rounded borders.
- **Input Sections:** Includes structured form controls for email and password entry with clear labels.
- **Interactive Elements:** Features a styled submission button and a recovery link ("Forgot Password?").
- **Vibrant Styling:** Custom color scheme featuring a gold background card, blue accents, and a khaki heading block.

## 🛠️ Tech Stack
- **HTML5** (Form structure, semantic labels, and inputs)
- **CSS3** (Flexbox alignment, custom border radius, and color styling)

## 📁 Code Overview
- `index.html`: Contains the core form layout, inputs, button, and navigation links.
- `style.css`: Handles global resets, card centering, layout spacing, and visual styling.

## 🚀 How to Run
1. Open the `day03` folder.
2. Launch `index.html` using a local server (like Live Server in VS Code) to view the login interface.
