# React Quiz App 🧠⚡

A clean, interactive, and modular 3-question Quiz application built with React and Vite. This project is **Day 09** of my 50-day coding challenge, focusing on conditional component rendering, complex state tracking, and user event handling.

## 🚀 Features
* **Dynamic Question Flow:** Step-by-step navigation through multiple-choice questions.
* **Instant Score Tracking:** Real-time state updates that tally your correct answers as you progress.
* **Results Screen:** Celebratory summary screen displaying your final score with a "Play Again" reset function.
* **Modular Architecture:** Cleanly separated components (`QuizCard`, `ScoreScreen`) paired with an external stylesheet (`App.css`).

## 🛠️ Built With
* **React** (State hooks & Component-driven architecture)
* **JavaScript (ES6+)**
* **CSS3** (Flexbox alignment, gradient backgrounds, and smooth button hover states)
* **Vite** (Next-generation frontend tooling)
* **Oxlint** (Blazing-fast code linting)
