# Day 4: Interactive Calculator — 50-Day Coding Challenge

A responsive, gradient-styled web calculator built with Vanilla JavaScript, HTML5, and CSS3.

## 🚀 Features
- **Dynamic Display:** Smoothly appends numbers and operators to a real-time input display.
- **Evaluation Logic:** Performs arithmetic calculations securely using JavaScript's `eval()` function inside a `try...catch` block to handle syntax errors gracefully.
- **Clear Functionality:** Includes a reset ("C") button to clear the display instantly.
- **Modern Styling:** Features custom linear gradients and flexible grid-like button alignment.

## 🛠️ Tech Stack
- **HTML5** (Structure & Event handlers)
- **CSS3** (Flexbox layout, custom gradients, and container styling)
- **Vanilla JavaScript** (DOM manipulation and calculation logic)

## 📁 Code Overview
- `index.html`: Contains the structural layout, input screen, and button grid linked to inline event functions.
- `style.css`: Manages the page layout, centering, responsive sizing, and gradient themes.
- `script.js`: Handles user interactions, appending values, clearing the screen, and evaluating expressions.

## 🚀 How to Run
1. Clone the repository or open the project folder.
2. Launch `index.html` using a local server (like Live Server in VS Code) to test the calculator interface.
