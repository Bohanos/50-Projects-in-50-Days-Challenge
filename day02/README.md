# Day 2: Simple Landing Page — 50-Day Coding Challenge

A clean, responsive landing page template built with HTML5 and CSS3 as the second project of the 50-day challenge. Featuring a brand called Bohanos.

## 🚀 Features
- **Multi-page Layout:** Includes Home (`index.html`), Features (`features.html`), and About (`about.html`) pages.
- **Hero Section:** Balanced grid layout for compelling product introductions.
- **Feature Cards:** Highlights key product advantages with a modern dark-theme aesthetic.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3 (Flexbox & Grid)**
