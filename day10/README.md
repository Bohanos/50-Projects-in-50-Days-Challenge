# Simple Grade Calculator 🈴🎓

A beginner-friendly, interactive Grade Calculator built with React and Vite. This project is **Day 10** of my 50-day coding challenge, focusing on managing multiple state variables, handling form submission events (`e.preventDefault()`), and performing basic arithmetic calculations to determine academic averages and letter grades.

## 🚀 Features
* **Multi-Subject Inputs:** Dedicated fields for four core subjects: English, Math, Computer Science, and Physics.
* **Automated Average Calculation:** Instantly computes the overall mean score divided by the 4 subjects.
* **Dynamic Letter Grading:** Automatically translates the numerical average into a letter grade (A, B, C, D, or F).
* **Smooth Form Handling:** Uses `e.preventDefault()` to process data cleanly without reloading the browser page and wiping out inputs.

## 🛠️ Built With
* **React** (State hooks `useState`)
* **JavaScript (ES6+)**
* **CSS3** (Flexbox alignment, container styling, and clear layout design)
* **Vite** (Blazing-fast frontend build tool)
