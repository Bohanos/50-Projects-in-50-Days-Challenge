# React Counter App ⏱️

A sleek, lightweight, and interactive counter application built with React. This project was developed as part of a 50-day web development coding challenge to practice state management and event handling in modern frontend development.

## 🚀 Features
* **Core Operations:** Increment, decrement, and reset functionality.
* **Reactive State:** Instant UI updates using React's state management.
* **Clean UI:** Minimalist and responsive design optimized for seamless user interaction.

## 🛠️ Built With
* **React** (Component-based architecture)
* **JavaScript / JSX** 
* **CSS3** (Styling & Layout)
* **Vite** (Build tool)

## 📦 Getting Started

To run this project locally, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Bohanos/50-Projects-in-50-Days-Challenge/tree/main/day06](https://github.com/Bohanos/50-Projects-in-50-Days-Challenge/tree/main/day06)

1. Navigate to the project directory:

Bash:
cd 50-Projects-in-50-Days-Challenge

2. Install dependencies:

Bash:
npm install


3. Run the development server:

Bash:
npm run dev


💡 What I Learned
Building this app reinforced core React concepts, specifically handling user events, managing component state with hooks, and structuring clean component logic for scalable frontend applications.
