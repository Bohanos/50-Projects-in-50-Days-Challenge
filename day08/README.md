# Softblush Beauty - "Launching Soon" Landing Page 🌸

A gorgeous, elegant, and responsive "Launching Soon" landing page built for **Softblush Beauty**[cite: 2]. This project is **Day 08** of my 50-day web development challenge, focusing on clean semantic HTML5, separate external CSS styling, flexible layouts, and aesthetic visual design.

## ✨ Features
* **Modern & Clean Aesthetics:** Designed with soft color tones, minimalist typography, and a balanced layout featuring a custom illustration.
* **Separated Architecture:** Cleanly decoupled structure using standalone HTML (`index.html`) and external stylesheet (`style.css`) files.
* **Responsive Layout:** Adapts smoothly across different screen sizes.
* **Interactive Elements:** Styled call-to-action buttons and social media links ready for engagement.

## 🛠️ Built With
* **HTML5** (Semantic markup)
* **CSS3** (External stylesheet, Flexbox/Grid alignment, custom typography)
* **Vanilla Web Standards** (No heavy frameworks or libraries)
